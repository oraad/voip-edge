Lifecycle dialogs

Each names the object and the consequence. Focus starts on Cancel; Esc closes.
Park home “beta”?

This home’s remote phones lose service in both directions; calls already in progress finish normally.

The console will: back up the routing database → snapshot 4 rows (home, landline, sets 12 & 32, trusted source) → remove them → reload routing → drop 2 cached registrations, verified.

Destroy home “beta” (active)?

Permanently removes the home and all its routing data, drops its live registrations, and discards the snapshot. The phone number rules shared with other homes stay untouched. This cannot be undone.

Restore home “legacy-x”?

Re-inserts the parked snapshot exactly as it was. Blocked if anything claimed its domain, ids, numbers, sets or source address since — nothing is overwritten.

Destroy parked home “legacy-x”?

Deletes its parked snapshot (4 rows · 2 KB). The edge already has no trace of this home; nothing else changes.
